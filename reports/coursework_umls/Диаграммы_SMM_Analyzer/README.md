# Диаграммы SMM Analyzer

Актуальная редакция после аудита. Откройте Сборник_диаграмм.html.

- 21 основная диаграмма, нумерация задания сохранена.
- 15A–C и 16A–C — изображения фрагментов двух общих моделей БД для читаемой вставки в отчёт.
- PNG — изображения; HTML — основные визуальные исходники; SVG — вектор; Drawio — редактируемые представления с фиксированными маршрутами.
- Теория — разбор всех типов с нашими картинками.
- ПРОЕКТ_СОГЛАСОВАННАЯ_МОДЕЛЬ.md — действующие правила, API, ограничения и версии.
- ИСПРАВЛЕНИЯ_ПО_АУДИТУ.md — статус F01–F10 и результаты проверки.
- Архив_до_правок_аудита.zip — предыдущий комплект. Старые генераторы в рабочей папке не являются источником актуальной редакции; повторно запускать их поверх неё нельзя.
