# Подготовка к защите: начни здесь

1. Открой [общий учебник с разбором всех 21 диаграмм](Учебник_UML_и_разбор_21_диаграммы.md).
2. Прочитай общую теорию нужного типа и связанные разделы оригинала Анисимова. Полные ссылки есть в учебнике и каждой карточке.
3. Открой свою карточку ниже: картинка, конкретные элементы, сценарий, обоснование, вопросы/ответы и связи с другими моделями.
4. Просмотри дополнения А–Г: технологические процессы, правила классов, составление с нуля и границы наших моделей.

Тексты написаны для подготовки, а не для вставки без редактирования в официальную пояснительную записку. Сам отчёт и диаграммы в этом обновлении не менялись. Это подробное объяснение и навигация по полным оригиналам; дословные тексты и все авторские рисунки лекций здесь не воспроизведены.
