# Первые четыре диаграммы

Откройте **Открыть_диаграммы.html** — это оглавление комплекта.

1. UC_01_context — контекст всей системы.
2. UC_02_campaigns — клиенты и кампании.
3. UC_03_import — импорт статистики и комментариев.
4. UC_04_reports — подготовка и публикация отчёта.

Для каждой схемы: HTML для просмотра, SVG для отчёта, drawio для правок. PNG добавлены для удобного просмотра картинок.

**Теория_и_разбор.md** содержит картинки, обозначения, разбор связей, сценарии и вопросы для защиты.

Комплект сделан отдельно от прежних черновиков. Обновление всего отчёта выполняется после согласования этих четырёх схем.
