# SMM Analyzer — материалы курсовой

Тема: «Проектирование информационной системы управления SMM-кампаниями и анализа эффективности видеоконтента».

Это комплект проектных моделей, без кода приложения и без итоговой пояснительной записки. Откройте `index.html` для просмотра всех диаграмм. Тексты разделов находятся в `01_Тексты` (Markdown), редактируемые исходники диаграмм — в `02_UML` (PlantUML), готовые SVG и PNG — в `03_Диаграммы`.

Файл `01_Тексты/00_Основание_и_решения.md` отделяет то, что действительно показано в трёх PNG примера, от принятых здесь проектных решений. `01_Тексты/06_Трассировка_и_проверка.md` связывает требования со сценариями и диаграммами. Обучение ML и написание приложения отложены.

Для пересборки изображений нужен PlantUML: `java -jar plantuml.jar -tsvg 02_UML/*.puml` (аналогично `-tpng`). Использован PlantUML 1.2025.10.

Для подготовки будущего отчёта начните с `01_Тексты/00_Паспорт_проекта_для_отчёта.md`, затем используйте `07_Пояснения_ко_всем_UML_диаграммам.md` и `08_Карта_сборки_отчёта.md`. Полнота по пунктам задания проверена в `09_Аудит_полноты_по_заданию.md`.
