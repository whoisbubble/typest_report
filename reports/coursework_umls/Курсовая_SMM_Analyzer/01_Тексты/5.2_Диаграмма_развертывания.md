# 5.2. Диаграмма развёртывания

DEP_01_Развёртывание показывает браузер и сервер агентства с Docker Engine. Внешняя точка входа — reverse proxy по HTTPS/443. Внутри закрытой сети доступны web:3000 и api:3001. PostgreSQL:5432 не публикуется наружу. Worker не принимает внешние соединения.

Контейнеры API и Worker имеют доступ к закрытому тому файлов импорта и БД; Next.js и proxy — не имеют доступа к этому тому. PostgreSQL хранит данные в постоянном томе. Secrets передаются через закрытые файлы окружения/секреты сервера, не включаются в образ или репозиторий.

Резервные копии БД и импортов шифруются и сохраняются отдельно от рабочего сервера. Ротация и восстановление относятся к эксплуатации. Один сервер — осознанное упрощение для учебного проекта, без заявления о высокой доступности.

Действующие внешние API соцсетей, сервис транскрибации и ML-инференс на схеме отсутствуют: это границы текущего объёма.
