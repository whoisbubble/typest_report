# Общий шаблон студенческой учебной работы

`report.typ` и `template.typ` в этой папке — ранее созданный параметризуемый образец. Функция `sur-report` принимает тему, вид работы (`work-type`), дисциплину, шифр, кафедру, студента и руководителя. Титул уже содержит две строки для подписей.

**СУР — общее обозначение студенческих учебных работ, а не точный вид документа.** На титуле указывайте конкретный вид: курсовая работа, курсовой проект, расчётно-графическая работа, отчёт по практике и т. п. Для КР и ВКР из комплекта `Student2027` используйте новые папки `../coursework/` и `../bachelor_thesis/`.

Этот старый шаблон ссылается в комментариях на пособие 2022 года, которого нет в `D:\downloads\Student2027`. В нём поля 20/15/20/30 мм и номер страницы по центру; презентация преподавателя для **КР, КП и ВКР** требует поля 30/10/20/20 мм и номер справа. Поэтому переносить старый шаблон на эти виды работ без замены правил нельзя.

Для другого вида СУР сперва определите его по заданию и соответствующему пособию. Без этих данных универсальное оформление нельзя подтвердить как соответствующее кафедральным нормам.
