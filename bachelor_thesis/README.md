# Шаблон ВКР бакалавра ДВГУПС 09.03.02 и 09.03.04

## Назначение файлов

- `template.typ` — оформление, обложка, титульный лист и функции объектов.
- `report.typ` — учебный образец пояснительной записки.
- `images/diagram.svg` — демонстрационный рисунок.
- `report.pdf` — контрольная сборка образца.

Собрать документ из этой папки: `typst compile report.typ report.pdf`.

## Источники и приоритет

1. `Учебно-методическое пособие по выполнению выпускной квалификационной работы - бакалавры ИСиТ и ПИН.pdf` (Калитин, Шестухина, Ешенко, Попов, 2023): с. 8–19 — состав и содержание; с. 20–30 — оформление; приложения Е, Ж, Л–Ф на с. 70–84 — образцы и стили.
2. `Оформление КП, КР и ВКР.pptx`: слайды 2–19 и 27 — конкретные параметры и минимум источников.
3. `СТ 02-16-17 Требования к содержанию и оформлению ВКР редакция 2.1.doc`: общая структура и рекомендуемый объём бакалаврской работы 50–60 страниц.
4. `ГОСТ Р 7.0.100-2018 Библиографическая запись. Библиографическое описание.pdf`: библиографическое описание. Более новый ГОСТ из комплекта применяется вместо упомянутых в старом стандарте прежних правил описания.

Файлы источников находятся в соседней общей папке `Стандарты и учебные пособия по оформлению КР, КП и ВКР`.

## Порядок частей

1. Обложка с описью документов — вне счёта страниц ПЗ.
2. Титульный лист — первая страница ПЗ, номер не печатается.
3. Утверждённое задание и отзыв руководителя — официальные бланки; в счёт страниц ПЗ не входят.
4. Англоязычная аннотация объёмом до одной страницы — входит в счёт, номер не печатается.
5. Содержание — входит в счёт, номер не печатается.
6. Введение; главы основной части; заключение; список использованных источников.
7. Определения, обозначения и сокращения; приложения — по необходимости.

Полный объём ПЗ бакалавра без приложений — **50–60 страниц**. `report.pdf` представляет только образец оформления объектов и не удовлетворяет требованию по объёму.

## Зафиксированные параметры

| Элемент | Правило |
| --- | --- |
| Лист и поля | A4, одна сторона; слева 30 мм, справа 10 мм, сверху и снизу 20 мм |
| Основной текст | Times New Roman 14 пт, по ширине, полуторный интервал, абзац 7,5 мм |
| Страницы | арабские цифры, сквозной счёт с титула, номер справа внизу начиная с введения |
| Заголовки | раздел с новой страницы; номера без конечной точки; без переносов слов |
| Таблицы | номер в пределах раздела, заголовок над таблицей, ссылка до таблицы |
| Рисунки | номер в пределах раздела, подпись под рисунком, ссылка до рисунка |
| Формулы | номер по разделу справа, расшифровка с «где» под формулой |
| Источники | не менее 15 наименований; каждый упомянут в основной части; описание по ГОСТ Р 7.0.100–2018 |
| Приложения | каждое с новой страницы, буквы кириллицей, ссылки из основной части |

Введение и заключение не содержат ссылок на источники, таблиц, рисунков и формул (пособие, с. 15–17). При первом использовании сокращения раскройте его. Для 09.03.02 используйте шифр `БР 09.03.02 <группа> ПЗ`, для 09.03.04 — `БР 09.03.04 <группа> ПЗ` (пособие, с. 13).

## Как писать работу с ИИ

1. Скопируйте папку, заполните вызов `bachelor-title` в начале `report.typ`: тема, направление, группа, кафедра, заведующий, руководитель, нормоконтроль, год. Параметры `consultant` и `consultant2` включайте только при официальном назначении консультантов; для каждого предусмотрены должность и степень.
2. Не изменяйте исходные функции `template.typ` без сверки с указанными страницами норм. Добавляйте реальные главы и объекты в `report.typ` по имеющимся примерам.
3. Заполните опись после фактической сборки. Вложите утверждённое задание и отзыв в конечный комплект. Подписи, допуск и нормоконтроль должны быть настоящими.
4. Замените аннотацию на точное краткое изложение своей работы на английском языке. Замените демонстрационный текст, числа, схему, код и источники.
5. Ведите список только по прочитанным источникам. Проверяйте для каждого пункт библиографии, ссылку в основной части и оформление описания.
6. Соберите PDF и просмотрите каждую страницу; отдельно проверьте переносы таблиц. Typst повторяет шапку через `table.header`, но слова «Продолжение таблицы…» и «Окончание таблицы…» при автоматическом переносе сам не добавляет: длинную таблицу нужно дооформить вручную.

Образец даёт техническую основу, но тема, содержание, комплект подписанных бланков и требования выпускающей кафедры проверяются перед сдачей конкретной ВКР.
