# Шаблоны и отчёты Typst

Личная коллекция шаблонов и готовых отчётов.

## Структура

- `coursework/` — шаблон и образец курсовой работы по новым материалам преподавателя.
- `bachelor_thesis/` — шаблон и образец ВКР бакалавра ИСиТ или ПИН.
- `workarea_template/` — ранее созданный общий шаблон СУР; он основан на более старом пособии и пока не сверён с новыми заданиями для конкретного вида работы.
- `reports/practice_report/` — готовый отчёт по практике вместе с изображениями и исходниками.
- `assets/` — общие материалы для будущих отчётов.

## Как начать новый отчёт

Для новой КР или бакалаврской ВКР используйте соответствующую папку выше и её `README.md`. Для другого вида студенческой учебной работы можно взять `workarea_template`, но сначала установить конкретный вид работы и применимое пособие: в новом комплекте `Student2027` отдельной формы для «просто СУР» нет.

Сверка с полным комплектом преподавателя и обнаруженное расхождение в нумерации содержания описаны в `FORMATTING_AUDIT.md`.

1. Скопировать папку `workarea_template` и дать копии понятное имя.
2. Редактировать `report.typ`; оформление и вспомогательные функции находятся в `template.typ`.
3. Положить изображения в `images/`, а листинги кода — в `src/`.
4. Собрать PDF командой:

   ```text
   typst compile report.typ
   ```

Готовые PDF хранятся рядом с соответствующими файлами `report.typ`.
