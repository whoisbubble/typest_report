# Шаблоны и отчёты Typst

Личная коллекция шаблонов и готовых отчётов.

## Структура

- `workarea_template/` — рабочий шаблон для создания нового отчёта.
- `reports/practice_report/` — готовый отчёт по практике вместе с изображениями и исходниками.
- `assets/` — общие материалы для будущих отчётов.

## Как начать новый отчёт

1. Скопировать папку `workarea_template` и дать копии понятное имя.
2. Редактировать `report.typ`; оформление и вспомогательные функции находятся в `template.typ`.
3. Положить изображения в `images/`, а листинги кода — в `src/`.
4. Собрать PDF командой:

   ```text
   typst compile report.typ
   ```

Готовые PDF хранятся рядом с соответствующими файлами `report.typ`.
